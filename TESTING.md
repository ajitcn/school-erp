# Testing

Run `php artisan test`, `php artisan migrate`, `php artisan db:seed`, `php artisan view:cache`, `composer validate`, and `git diff --check` in a configured development environment. Feature coverage targets login/session regeneration, permission and branch isolation, user/role assignment, duplicate student IDs, unique attendance, fee allocation/refund/receipt workflows, expense approval, import validation, report filters/exports, student/parent ownership, tenant registration/owner creation, tenant context isolation, and suspended tenant access. Automated tests were not run during the 2026-10-30 implementation pass.

PHP syntax, route registration, Blade compilation, and migrations against in-memory SQLite were checked during that pass. `npm.cmd install` and `npm.cmd run build` may require registry access. Student input import supports XLSX using PHP's Zip extension; report exports are generated by the app's built-in CSV/XLSX/PDF paths.
