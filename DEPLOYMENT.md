# Deployment

Configure PHP >= 8.4.1, Composer, MySQL, a queue worker, and a web server pointing to `public/`. Set `APP_ENV=production`, `APP_DEBUG=false`, a unique `APP_KEY`, database credentials, a production mail transport, and HTTPS session settings. Back up the database, then run `composer install --no-dev --optimize-autoloader`, `php artisan migrate --force`, `php artisan config:cache`, `php artisan route:cache`, and `php artisan view:cache`.

Run `php artisan queue:work --tries=4` under a process supervisor for external email, SMS, and WhatsApp notifications. The notification job uses staged backoff delays. Configure a transactional database queue or Redis; monitor failed jobs with `php artisan queue:failed` and retry after fixing provider configuration. The scheduler should run every minute for subscription expiry and fee reminder tasks.

Platform administrators can configure SMTP, Twilio, and Razorpay under **Platform settings**. Provider secrets are encrypted using `APP_KEY`; keep it backed up and stable. Environment variables remain available as defaults until a platform override is saved. For deployment automation, the same providers can still be configured through `.env`. Start with Razorpay test credentials, verify the full checkout and captured-payment flow, then switch to live credentials. Without keys, owners can continue submitting manual payment references for platform review. Twilio delivery requires an approved sender and E.164 phone numbers; email delivery requires a valid SMTP or server mail transport.

Back up MySQL before migrations and retain encrypted backups. Never use `migrate:fresh` in a shared environment. Use status transitions/refunds/reversals for financial corrections.

Subscription expiry is enforced on tenant requests and by the `subscriptions:expire` scheduled command. Fee reminders run with `fees:send-due-reminders` at 08:00 daily for unpaid installments due within seven days; each linked student or guardian account receives at most one reminder per fee item. Tenants can configure the `fee.due_reminder` template to use in-app, email, SMS, or WhatsApp delivery. Configure Laravel's scheduler to run every minute (for example, `* * * * * cd /path/to/application && php artisan schedule:run >> /dev/null 2>&1`) so both scheduled tasks run even when no tenant is signed in. Keep billing routes accessible after expiry for renewal.
